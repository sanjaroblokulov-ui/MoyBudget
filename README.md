# Мой бюджет

Персональное Android-приложение для планирования и учёта расходов.

- Русский / O‘zbekcha
- Тёмная / светлая тема
- Доход отдельно по месяцам
- Группы и подкатегории расходов
- Дата каждой покупки
- Лимиты и предупреждения
- Сравнение месяцев
- Локальное хранение без синхронизации

## Сборка

Проект собирается через GitHub Actions. APK публикуется как workflow artifact.
